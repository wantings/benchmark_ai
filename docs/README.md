# Benchmark AI

A static archive of publisher-reported and third-party AI benchmark scores. Sources, model configurations, and evaluation conditions remain visible.

Serve this directory locally or publish it with GitHub Pages. There are no server dependencies or credentials. Raw downloaded pages, full search results, screenshots, and local research files are excluded. Reusable curated data is available in `extracted/`.

Third-party data includes Artificial Analysis public evaluations and Epoch AI data (CC BY 4.0). Original external sources retain their own attribution; see the website source library. Scores are historical snapshots, and highlighted differences are review signals rather than confirmed contradictions.
